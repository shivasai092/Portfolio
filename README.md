## 🚀 Running Locally

No build tools or frameworks are required.

1. Download or clone the repository.
2. Keep `index.html` and `profile-photo.png` in the same directory.
3. Open `index.html` in a modern web browser.

## 🌐 GitHub Pages Deployment

This portfolio can be hosted directly using GitHub Pages.

1. Push the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Go to **Pages**.
4. Select the required branch as the deployment source.
5. Save the settings.
6. GitHub Pages will publish the website.
